This is the flow you should be able to explain on a whiteboard.

Accepted

Valid record

Map columns, cast types, standardize values, run quality checks, then compare tracked attributes with the current Silver version.

Rejected

Invalid record

Keep it traceable in quarantine with the rule name, reason, raw value, batch ID and source row. Never silently drop it.

Golden rule: Bronze preserves what arrived. Silver decides what it means. SCD2 records how meaningful business attributes change over time.
